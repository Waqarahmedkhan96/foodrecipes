# Tasty Pakistan by Fatma

A luxury recipe and inspiration website for Pakistani home cooking.

## Stack

- **Pages:** static HTML, generated by a small Python script (`build.py`, standard library only)
- **Styling:** hand-written CSS with design tokens (`assets/style.css`), Google Fonts
- **Behaviour:** vanilla JavaScript, no framework (`assets/site.js`)
- **Content:** JSON files in `data/`
- **Hosting:** Vercel (static), configured in `vercel.json`

## Pages

| Page | File |
|---|---|
| Home | `index.html` |
| All recipes, filterable | `recipes.html` |
| One page per recipe | `recipes/<recipe-id>.html` |
| Fatma's story | `story.html` |
| Ask Fatma (questions and requests) | `ask.html` |
| Journal and articles | `journal.html`, `journal/<slug>.html` |
| Spice guide (SEO articles) | `spices.html`, `spices/<slug>.html` |

Category links open the recipes page already filtered, for example `recipes.html#chicken`, `recipes.html#col-eid`, `recipes.html#veg` or `recipes.html#search-biryani`.

## Adding or editing a recipe

1. Add the dish photo to `images/` as `<recipe-id>.jpg`.
2. Add or edit the recipe in `data/recipes.json`.
3. Run `python3 build.py`. It rebuilds every page, including the new recipe page.

Journal articles live in `data/journal.json` and spice guides in `data/spices.json`. Set `SITE_URL` at the top of `build.py` once the domain is known to also generate `sitemap.xml`, `robots.txt` and canonical links. The home page choices (featured slider, Fatma's picks, recipe of the week, popular searches) are at the top of `build.py`.

## Folders

- `assets/`: `style.css`, `site.js` and the generated `data.js`
- `data/`: recipe and journal content
- `images/`: photography
- `src/`: shared page sections and icons used by `build.py`

## Run locally

Open `index.html` in a browser, or run `npx serve .` in this folder.

## Deploy

The generated pages are committed, so the host only serves files and there is no build step. `vercel.json` sets security headers and caching. On Vercel, import this repository with the framework preset set to "Other". Any static host (Netlify, Cloudflare Pages, nginx, Apache) works the same way; serve `404.html` for missing pages.

## Before launch

The subscription and query forms only show a confirmation on screen. Connect them to an email or newsletter service (for example Formspree, Mailchimp or ConvertKit) to receive submissions. Saved recipes are stored in each visitor's own browser.
